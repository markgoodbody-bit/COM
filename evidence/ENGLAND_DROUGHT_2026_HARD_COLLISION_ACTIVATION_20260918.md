## Thin activation

### Shared world state

Finite surface water / groundwater / reservoir capacity under drought.

### Material scopes

```text
S_public = household/business public water supply
S_food = agricultural abstraction / crop / livestock use
S_env = river flow / aquatic ecosystem / water quality
S_nav = navigation / recreation / water-based local activity
S_future = winter recharge / next-season resilience
```

These labels are analysis scopes, not claims that each is a moral person or has equal standing.

### Clocks

```text
T_crop = current harvest / crop-lifting / livestock/fodder needs
T_env = current low-flow / fish / habitat / water-quality stress
T_public = current supply + autumn/winter storage
T_recharge = winter groundwater/reservoir refill window
T_next = spring/summer 2027 resilience
```

The clocks are not automatically commensurable.

### Controls / authority

```text
water companies -> customer restrictions / drought plans / supply measures
Environment Agency -> abstraction restrictions / permits / environmental intervention
Defra / Secretary of State -> specified drought orders
licence holders -> use within or below authorised conditions
National Drought Group -> coordination / evidence / preparedness, not one universal value source
```

Authority remains external to TRACE.

### Deliberate contractions

Examples already owned by the domain system:

- hands-off-flow / Section 57 restrictions narrow agricultural abstraction;
- temporary/non-essential-use restrictions narrow household/business uses;
- navigation restrictions narrow waterway access;
- drought permits/orders may increase flexibility for public supply while creating environmental questions;
- environmental protection may require leaving water in rivers rather than abstracting it.

These are not representable honestly as 'all option closure = harm'.

### Burdens

Keep burden typed rather than summed into one score:

```text
agriculture: crop loss / business disruption / forage risk / reservoir refill constraint
public supply: use restrictions / shortage risk / future resilience burden
environment: low flow / fish mortality / habitat / water-quality damage
navigation: closure / business / access impacts
future users: reduced stored/recharged water
```

TRACE can place these in separate dimensions/scopes. It cannot add them without a declared measure.

### Collision

A drought action can produce:

```text
PROTECT S_env
-> NARROW S_food

PROTECT S_public
-> POSSIBLY NARROW S_env OR S_food

PROTECT CURRENT S_food
-> POSSIBLY NARROW S_env OR S_future
```

Those arrows are generic physical/policy relations. Specific decisions require domain evidence.

## Does the project generate an allocation answer?

**No.**

Nothing in released TRACE/ME determines:
- the optimal abstraction amount;
- the correct Section 57 threshold;
- whether food production, ecology or public supply should dominate in a specified catchment;
- how different ecological/economic/social burdens should be numerically weighted;
- which party's hardship justifies overriding another's claim.

Any such result requires explicit external law, policy, evidence, value/measure and legitimate authority.

## Does the project still add something?

In this bounded pass, only a modest representation function survives:

- it keeps the distinct affected scopes visible;
- it keeps their clocks separate;
- it prevents burden from becoming one hidden scalar;
- it exposes who authored the restrictions / comparison measure;
- it makes deliberate path closure visible without automatically classifying it as wrongdoing;
- it can hand off at the point where domain allocation / legitimate value choice begins.

The Environment Agency's own drought framework already does substantial multi-sector representation and explicit trade-off work.

Therefore no domain-analysis advantage is established.
