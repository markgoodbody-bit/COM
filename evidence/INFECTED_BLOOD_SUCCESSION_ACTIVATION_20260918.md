## Question

> Can the current succession language describe a real institutional repair obligation that survives changes of actor and mechanism without inventing personal identity continuity?

## Result

**Yes. No new project primitive is required.**

Current scheme evidence supports:

```text
PAST HARM
-> INSTITUTIONAL / STATUTORY REPAIR OBLIGATION
-> CURRENT SUCCESSOR ADMINISTRATOR
-> CLAIM / PAYMENT / REVIEW
-> CHANGED REGULATIONS / RECALCULATION
-> FUTURE SUPPORT-PAYMENT TRANSFER
```

Load-bearing distinctions:

```text
SUCCESSOR_NOT_CULPABLE != INSTITUTION_NO_LONGER_OBLIGATED
HONOUR_REPAIR_COMMITMENT != FREEZE_REPAIR_METHOD
PURPOSE != MECHANISM
ROLE / OBLIGATION CONTINUITY != PERSONAL IDENTITY CONTINUITY
DURABLE PURPOSE != INSTITUTION MUST EXIST FOREVER
PAYMENT_MADE != EVERY FUTURE REVIEW CLOSED
```

## What the owner already does

IBCA / the statutory scheme already owns:
- eligibility and award calculation;
- review/rework after scheme changes;
- current compensation payment;
- transfer of continuing support responsibilities;
- claimant communication / feedback;
- transition implementation.

Thus the project adds no compensation-domain rule.

## Project consequence

The case is a strong field witness for the Open Horizon succession route because the same repair purpose persists while:
- office-holders change;
- rules evolve;
- payment mechanisms change;
- administrative bodies change;
- some earlier decisions are reopened under later rules.

This is precisely the kind of continuity that does **not** require saying the successor is the same person/entity as the predecessor in every sense.
