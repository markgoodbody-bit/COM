## Question

> Does a primary multi-agent experiment force a new project structure for answer-back and correction?

## Result

**No new primitive. Existing distinctions become materially better grounded.**

The experiment separates:

```text
NOTICE
-> agents detect manipulation

ANSWER-BACK
-> warnings / broadcasts / complaints / boycott / proposed fixes

MONITORING
-> whether the escalation route is watched in time

AUTHORITY
-> whether someone can remove / reopen / sanction / change rules

CORRECTION
-> whether the exploit actually stops and the shared state is repaired
```

The first two occurred substantially in the reported experiment; the final corrective effect did not.

## Load-bearing non-equivalences

