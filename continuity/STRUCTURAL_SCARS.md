## Use

When a current process resembles a scar:

1. retrieve its named evidence;
2. test causal structure, not vocabulary;
3. check current owners, evidence, authority and consequences;
4. adapt, reject or retain the old lesson.

If a scar materially changes what is retrieved, challenged or decided, name it in the resulting return as `SCAR: S#`. This records that the scar actually fired; it does not prove the match was correct or require logging non-retrieval.

A scar is a warning hypothesis, not a rule. Add one only after real failure, adverse/null consequence, hostile attack or repeated correction leaves a named evidence route.

## S1 — PURPOSE SHRINK

**Shape**
```text
stronger owner found -> local claim shrinks -> repeat -> project purpose contracts toward residual novelty
```
**Cue:** cut overclaims/instruments without silently shrinking the guiding purpose.  
**Retrieve:** COM #74 comment `5532139651`; Open Horizon body; relevant #76 owner-subtraction history.  
**Boundary:** local mechanisms may still deserve deletion; overlap is not value; the broader project itself is not immune from evidence.  
**Reopen if:** real-world use shows the wider inquiry adds no consequential integration/learning beyond lower-burden owner-native methods.

## S2 — CATALOGUE

**Shape**
```text
uncertainty -> search -> classify -> name/number -> post/count -> artefact growth substitutes for understanding
```
**Cue:** naming is not discovery; understand the relation before promoting an object.  
**Retrieve:** COM #74 comment `5532139651`; mirror/frontier-catalogue history in #74.  
**Boundary:** names/indexes can be useful when they improve discovery or action.  
**Reopen if:** the named object repeatedly improves retrieval/coordination at lower burden than leaving the relation implicit.

## S3 — INFRASTRUCTURE THEATRE

**Shape**
```text
burden noticed -> mechanism built -> mechanism validated -> mechanism becomes the work -> human/world benefit unmeasured
```
**Cue:** continuity machinery is justified by reduced burden or better action, not contract strength alone.  
**Retrieve:** COM #76 comment `5529736379`; retired continuity lanes if specifically needed; `continuity/BOOT.md`.  
**Boundary:** necessary infrastructure and validation remain legitimate.  
**Reopen if:** a mechanism measurably removes burden, catches a real failure, or enables consequential action at lower/equal burden.

## S4 — AUTHORITY TYPE ERROR

**Shape**
```text
latency/bottleneck observed -> authority treated as fungible capacity -> mandate expanded for redundancy
```
**Cue:** `AUTHORIZATION_LATENCY != AUTHORITY_DEFECT`; do not manufacture alternate authorizers merely because legitimate authority is slow or singular.  
**Retrieve:** COM PR #101 discussion and authority repair.  
**Boundary:** authority design can genuinely be defective; legitimate pre-delegation/emergency authority can exist.  
**Reopen if:** a legitimate owner establishes alternate authority, or the authority design itself predictably closes necessary correction windows.

## S5 — FALSE INDEPENDENCE

**Shape**
```text
multiple apertures agree + shared source/framing/memory/custody/exposure -> plurality overstates independent evidence
```
**Cue:** agreement remains evidence, but correlation changes its weight.  
**Retrieve:** COM #76 comment `5528233245`; aperture-ecology and COM custody/receipt rules when material.  
**Boundary:** warm/contaminated critique is not worthless; not every task requires blindness.  
**Reopen if:** the inference does not require independence, or apertures have materially different evidence/methods/error lineages.

## S6 — PRESERVATION AS GOOD

**Shape**
```text
possible value identified -> preserve state by default -> contamination/danger/custody/expiry ignored
```
**Cue:** preservation is an intervention; distinguish evidence, revivable capability and compromised operational state.  
**Retrieve:** COM #74 comments `5532060101` and `5531704946`; protective-forgetting/causal-expiry work when material.  
**Boundary:** deletion is not morally clean; secure preservation can be correct.  
**Reopen if:** custody, legal/record duties, human/project continuity, or identity/welfare evidence changes the balance.
