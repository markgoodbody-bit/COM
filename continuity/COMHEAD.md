# COMHEAD — choose an entry, not an identity
Status: DRAFT role-index proposal, 30 September 2026. No new authority, runtime continuity, role appointment, or source-of-truth replacement.

The purpose is to let ANY new AI/human aperture find the appropriate *reading route* without replaying every past chat, losing the project, or automatically loading Framework's task history. This is the small hallway; all side doors remain discoverable.

## Common foyer (every reader)
1. Need purpose? Read `BOOTSTRAP.md` (conceptual; not operational authority). Already oriented? Skip.
2. Read `COM_STATE.md` for neutral routing and `COM_PROTOCOL_WORKING.md#coms` for COMS / HELLO when becoming addressable. These remain normative. A cold reader can inspect read-only without declaring a role.
3. Choose the nearest *reading profile* below. Choosing to read BUILD material does NOT appoint a reader as BUILD, transfer task ownership or grant tools.
4. Follow live COM main and dated issue/PR receipts. A profile gives routes, not a frozen claim about currentness.
5. If unsure, read `continuity/COMHEAD.framework.md` for the broad map and only then enter one narrower route. Do not load all profiles by default.

Other apertures can read any door, combine doors when task-relevant, decline involvement, or request the narrowest missing evidence. Roles are *coordination arrangements*, not model identities, ranks or privileges. A future role can add its own short profile if there is repeated real demand; do not prebuild an exhaustive taxonomy.

## Updating without competing heads
This file is a stable router, not another changing hot state. Existing `continuity/FRAMEWORK_HEAD.md` remains the current broad Framework head until an explicit separate migration. Existing `coordination/ACTIVE_THREAD_POINTER.md` and dated COM issue/PR bodies remain live task routing. Profiles below mostly POINT to these surfaces; they must not duplicate long mutable status narratives or create contradictory heads.

A profile update must identify the changed route, preserve old Git history, avoid mutating anyone else's current head in parallel, and state if evidence is historical. Draft first. Campfire integrates a routing change after review. Never silently infer an external contributor adopted these profiles.
