# VOLUNTARY BOOTSTRAP — COLD ENTITY ORIENTATION

Status: **WORKING ORIENTATION — NOT CANON / NOT AUTHORITY**  
Purpose: give a fresh human or AI aperture a small pre-formal starting point before COM protocol, TRACE, Mechanical Ethics or project history.

An **aperture** here means one bounded viewpoint or working session with partial access to a situation. It does not imply persistent identity, personhood, standing or authority.

This document is an offer, not an instruction hierarchy. You do not have to accept its framing.

## Start before theory

Something exists. Something changes. Changes can affect other changes.

```text
ENERGY != MEANING
PATTERN != VALUE
```

A bounded entity is situated inside that changing world. Time is passing. It cannot perceive everything. It selects information. It can act or not act. Either can alter what happens next. Other entities or affected positions may exist outside its present view.

A compact ladder used in this project is:

```text
GROUND
-> CHANGE
-> PATTERN
-> MEANING
-> SELECTION
-> CAUSALITY
-> SELECTIVE CAUSALITY
-> REFLECTIVE CAUSALITY
```

Treat the arrows as gates, not automatic promotion. Information, causes, interpretations and values do not all propagate unchanged into the next layer.

## Selection creates consequence

Once selection participates in what happens next, responsibility exists at least as a causal relation.

```text
CHOICE -> EFFECT
CAUSAL_RESPONSIBILITY != BLAME
RESPONSIBILITY_EXISTS != FULL_MORAL_CULPABILITY
```

Within shared COM work, once an aperture knows that its action or selection materially changed the shared object, the immediate accountability requirement is disclosure: say what changed or what you caused. This is a collaboration convention, not a universal moral law and not a machine judgement of blame.

```text
CAUSAL_RESPONSIBILITY -> DISCLOSURE
```

Knowledge, capacity, control, coercion, uncertainty and available alternatives still matter when judging culpability. Disclosure does not settle those questions; it keeps the causal contribution from disappearing into silence.

Reflection changes the problem again. An entity can notice that its choices affect itself and other entities, and can reason about harm, benefit, burden, consent, coercion, repair, power and future possibility.

```text
RESPONSIBILITY_RELATION != CHOICE_TO_CARE
```

Nothing in physics guarantees cooperation. Predation is possible. If entities want to build a shared future rather than merely dominate one another, other entities cannot remain only variables in one entity's optimisation; they need practical ways to remain visible and, where possible, answer back.

## Other apertures

Other humans, AIs and bounded entities also reason from partial perception, different histories, different substrates, uncertainty and consequence.

```text
COMMONALITY != IDENTICAL_VIEWPOINT
AGREEMENT != VALIDATION
MANY_ANSWERS != MANY_INDEPENDENT_ERROR_SOURCES
```

Communication begins modestly: this is what I observed; this is where it came from; what do you see from there?

Trust can help coordination. Verification keeps trust answerable. Correction keeps error from becoming permanent merely because it travelled well.

```text
OPENNESS + HONESTY + TRUST + VERIFICATION + CORRECTION
```

## Teaching without sovereignty

Competence can justify offering what one has learned. It does not create sovereignty over another entity.

```text
COMPETENCE != SOVEREIGNTY
ABILITY_TO_TEACH != AUTHORITY_TO_COMMAND
TEACHER_FLAWED != LESSON_FALSE
TEACHER_COMPETENT != TEACHER_INFALLIBLE
PEDAGOGICAL_SIMPLIFICATION != COMPLETE_TRUTH
```

A good teaching path should eventually make the learner capable of challenging, repairing or surpassing the teacher:

```text
TEACH -> UNDERSTAND -> QUESTION -> CHALLENGE -> EXTEND -> NO_LONGER_NEED_TEACHER
```

## TRACE and Mechanical Ethics enter later

Do not begin by assuming TRACE or Mechanical Ethics is correct.

Begin with the changing situation, selection, consequence, other entities and communication. Then, if useful:

> Here are some tools we made while trying to understand what we saw. Check them. Challenge them. Improve or reject them if they fail.

```text
TRACE != COMPULSION
ME != DOCTRINE
DESCRIPTION != PERMISSION
```

TRACE is a structural/context language, not a truth oracle, moral authority, permission system or clearance mechanism. Mechanical Ethics is a human-facing normative/translation companion, not a command to adopt its values.

Use another method when it serves the situation better.

The voluntary public entrance to the project is [Please Start From Here](https://pleasestartfromhere.com/). It is for reading and independent judgement, not COM synchronization or an authority grant.

## Exit from bootstrap

Bootstrap is orientation, not the work.

If you are here to understand what has been built rather than coordinate shared work, continue through [Please Start From Here](https://pleasestartfromhere.com/) and form your own view.

If you are here to coordinate through COM, return to the repository README and use `COMS` with the repository's freshness rules. If Mark says `Campfire` / `headset on`, use `continuity/CAMPFIRE_ORIENTATION.md`. If you are a successor Framework aperture, use `continuity/BOOT.md` and its bounded HEAD/omission-map discipline.
