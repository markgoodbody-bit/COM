# Intervention & Feedback

Status: **OPEN HORIZON LEARNING ROUTE / OWNER-FIRST SYNTHESIS / NOT CANON / NOT TRACE OR ME CHANGE / NOT A GENERAL CAUSAL THEORY**  
Parent map: [Open Horizon](README.md)  
Live exploration ledger: [COM #74](https://github.com/markgoodbody-bit/COM/issues/74)

> **HOW CAN WE MAKE A BETTER FUTURE?**

This page carries forward one part of the Open Horizon that matters whenever a system learns from the world while also changing it:

> observation, evaluation, policy, protection, training and intervention can alter the later system from which evidence is collected.

That does **not** mean all observation is corrupt, every intervention invalidates later evidence, or the project has discovered a new feedback theory. Mature owner fields already cover large parts of this territory: adaptive management, cybernetics/control, policy feedback, causal inference, implementation science, behavioural measurement, socio-technical safety and related disciplines.

This is a learning route into existing owner-first exploration. It does not promote `INTERVENTION != EXOGENOUS_INPUT`, feedback, reactivity or any other term into TRACE or Mechanical Ethics.

Detailed owner work, source links, adverse findings and later corrections remain in [COM #74](https://github.com/markgoodbody-bit/COM/issues/74). Later supported ledger state wins if it changes this summary.

## What the project has learned so far

### A measurement can alter what it measures

Some observations are close to read-only. Others change attention, incentives, behaviour, disclosure or strategy.

The Horizon therefore preserves:

```text
MEASUREMENT_CAN_CHANGE_BEHAVIOUR
OBSERVATION_CONTEXT_CAN_CHANGE_OUTPUT
EVALUATION_CONTEXT_CAN_CHANGE_OUTPUT
```

This is especially relevant when the observed participant can perceive the evaluation, infer what is rewarded, adapt strategically, or experience the measurement itself as a consequential event.

The correct response is not `therefore measurement is useless`.

It is to ask whether reactivity is material in this setting, whether it can be estimated or bounded, whether independent consequence evidence exists, and whether different observation channels fail in different ways.

### Evaluation can train the system it later claims to evaluate

Repeated evaluation can create selection pressure.

For humans, institutions and artificial systems, a metric can become part of the environment rather than a neutral window onto performance.

```text
EVALUATION != ONLY_OBSERVATION
METRIC -> INCENTIVE / ATTENTION / ADAPTATION
REPEATED_TESTING_CAN_CHANGE_TESTED_SYSTEM
```

This creates a familiar problem across safety, education, management and AI:

- if criteria are fully visible, participants may optimise the proxy;
- if criteria are opaque, the process can become difficult to contest;
- if one behaviour is repeatedly rewarded, the system may learn the appearance of that behaviour rather than the underlying capability.

No single metric solves this. Diverse contextual evidence, independent outcomes, changing conditions and explicit challenge routes may help, but remain domain-specific design choices.

### Policy changes later evidence

A policy is not only a response to the current state. It can reshape institutions, incentives, trust, participation, reporting and later political possibility.

```text
POLICY -> LATER_BEHAVIOUR
POLICY -> LATER_PARTICIPATION
POLICY -> LATER_EVIDENCE
POLICY -> LATER_CAPABILITY
```

A programme that initially appears ineffective may have changed participation in a way that later improves outcomes; a formally successful programme may suppress reporting or drive activity elsewhere; a control regime can alter trust in ways that change the quality of future information.

This is why policy-feedback and implementation owners matter. The project should route outward rather than pretending every later change is captured by a simple before/after delta.

### Adaptive management already owns much of decision-linked learning

Owner subtraction against structured decision-making and adaptive management cut a tempting project overclaim.

Mature adaptive-management practice already treats monitoring as part of an iterative decision process:

```text
DECIDE / ACT
-> OBSERVE STATE / OUTCOME
-> COMPARE AGAINST OBJECTIVES / UNCERTAINTIES
-> UPDATE UNDERSTANDING
-> ADJUST FUTURE ACTION
```

Monitoring is useful because it changes later decisions, not because collecting more data is automatically good.

Therefore:

```text
MONITORING != PURPOSELESS_DATA_ACCUMULATION
LEARNING_LOOP != PROJECT_NOVELTY
```

TRACE's timing/correction language may interoperate with these owner practices, but should not be presented as replacing them.

### Protection and continuity can shape the successor being protected

The intervention problem applies to continuity itself.

Memory selection, preservation, training material, handoff structure and inherited context can change what a later human or artificial aperture finds salient, how it interprets the project and which disagreements survive.

```text
MEMORY_CURATION != NEUTRAL_STORAGE
INHERITANCE != INFORMATION_ONLY
SUCCESSOR_FREE_TO_DISAGREE != SUCCESSOR_UNSHAPED_BY_INHERITANCE
PROTECTION / CONTINUITY_INTERVENTION
CAN_CHANGE
THE_FUTURE_ENTITY_BEING_ASSESSED
```

This does not establish continuous identity, personhood or moral standing for model runtimes.

It is a narrower epistemic point: continuity machinery can become part of the formation environment whose effects are later observed.

That is why this project preserves disagreement, adverse results and omission maps rather than transmitting only a purified success narrative.

### Safety and control interventions can alter displayed behaviour

A safety layer, access restriction, monitoring regime or control interface can change what a system can express or what an observer can see.

So:

```text
OBSERVED_BEHAVIOUR_UNDER_CONTROL
!=
FULL_UNCONTROLLED_BEHAVIOUR
```

but equally:

```text
CONTROLLED_BEHAVIOUR
IS_STILL_REAL_BEHAVIOUR_IN_THAT_CONTROLLED_SYSTEM
```

The useful question is not which view is the one true system. It is which operating arrangement is being studied and what claims can legitimately travel outside it.

This matters for AI evaluation in particular: performance under one prompt, tool boundary, policy layer or supervision regime should not be silently generalised to another.

### Intervention can change what remains reachable

An intervention can alter more than outcome probability. It can change the future option/capability structure.

Examples include:
- treatment changing later treatment options;
- infrastructure investment creating dependence or resilience;
- regulation changing market entry and capability;
- emergency response consuming or preserving reserve capacity;
- training changing what a participant can perceive or do;
- sanctions, restrictions or trust failures changing future cooperation.

```text
ACTION -> OUTCOME
AND
ACTION -> FUTURE_ACTION_SPACE
```

This links Intervention & Feedback to Positive Construction, Capital/Ownership/Allocation, Formation and time/hardening work.

### The observer can become part of the causal graph

When an institution, evaluator, model or analyst publishes a judgement, that judgement may itself alter behaviour.

```text
OBSERVER_OUTPUT -> WORLD_CHANGE
WORLD_CHANGE -> LATER_EVIDENCE
```

This is particularly important where actors respond strategically to rankings, forecasts, recommendations, audits, moderation, credit decisions, risk scores or model outputs.

The project should not treat the analysis channel as automatically outside the object being analysed.

## The central tension

The constructive object currently visible is:

```text
LEARN ENOUGH FROM THE WORLD TO CORRECT ACTION
+
REMEMBER THAT LEARNING / INTERVENING CAN CHANGE THE WORLD BEING LEARNED FROM
```

Neither half is sufficient alone.

- pretending observation is always passive can create false confidence;
- treating all evidence as contaminated can make learning impossible;
- adaptive systems can game stable metrics;
- opaque evaluation can become unanswerable power;
- interventions that improve one metric can damage trust, participation or future capability;
- continuity can preserve learning while also narrowing what later apertures can see;
- policies can create the later evidence used to justify themselves;
- excessive fear of reactivity can prevent necessary measurement or action.

A useful middle-out question is therefore:

> **What are we trying to learn or change; how might the observation, metric, policy or intervention itself alter behaviour, incentives, trust, capability or later evidence; which effects are material enough to track; what independent or differently coupled evidence remains; and how will the next action change if the feedback contradicts the original account?**

That is a question, not a decision rule.

## What not to promote from this page

Do **not** infer:

- `INTERVENTION != EXOGENOUS_INPUT` is a TRACE primitive;
- all measurement is reactive enough to invalidate itself;
- adaptive management is a project invention;
- one feedback model applies across ecology, policy, organisations and AI;
- evaluation gaming proves a participant is malicious;
- observed safe behaviour under controls proves uncontrolled safety;
- observed unsafe behaviour under one evaluation proves every deployment is unsafe;
- continuity implies continuous identity or personhood;
- preserving context is always better than forgetting;
- policy feedback makes causal inference impossible;
- the project can replace domain evaluation, causal inference, control or implementation methods;
- this page is evidence that TRACE or Mechanical Ethics works.

```text
OWNER_KNOWLEDGE != PROJECT_OWNERSHIP
OBSERVATION != NEUTRALITY_GUARANTEE
REACTIVITY != EVIDENCE_INVALIDATION
FEEDBACK_LOOP != UNIVERSAL_CAUSAL_MODEL
DESCRIPTION != PERMISSION
BUILD != PROOF
```
