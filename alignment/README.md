# Formation Under Uncertainty

Status: **WORKING ALIGNMENT LAYER / NON-PRODUCTION / NOT CANON / NOT ALIGNMENT SOLVED**

> **HOW CAN WE MAKE A BETTER FUTURE?**

This directory is the current project entry surface for work on formation and reciprocal human–AI development under uncertainty.

The working wager is narrow:

> If artificial capability grows under irreducible uncertainty, deliberately build relationships and environments in which affected others remain materially real, uncertainty creates work, authority stays explicit, challenge remains possible, correction remains reachable where it genuinely can, and care changes how burden and power are used.

This does **not** claim that care has been internalized, that a system is conscious or a person, that deception is solved, or that relationship design can replace interpretability, control, security or scalable oversight.

## How the current pieces relate

Do not flatten the environment candidate and the relationship architecture into one claim.

Formation Environment v0.2 asks whether a bounded episode can keep evidence, affected scope, challenge, authority, route usability, clocks, hardening, correction and residue explicit enough to inspect. Its validator can enforce some representation and consistency rules; it cannot establish truth, legitimate authority, standing, consent or internalized values.

Reciprocal Formation asks a different relationship-level question: how can initiative, challenge, dependence, human correction capacity, care and power change over time without either obedience or competence hardening into sovereignty?

Its harder ceiling remains:

> **CARE_EXPRESSED != CARE_INTERNALIZED**

We can build conditions that make care-like reasoning, evidence-bearing challenge and burden-awareness more usable without knowing whether those dispositions are internally stable, sincere, strategically performed, or even the right psychological ontology for a future system.

```text
ENVIRONMENT_RECORD != RELATIONSHIP_WHOLE
REPRESENTATION != INTERNALIZATION
PARTICIPATION != PERSONHOOD
CAPABILITY != AUTHORITY
```

The pieces can inform one another without becoming a compulsory combined workflow.

## Stronger owners still lead

This project does not currently solve:
- deceptive alignment;
- mechanistic interpretability;
- hidden long-horizon objectives;
- secure containment;
- authenticated permission enforcement;
- scalable oversight of superhuman cognition;
- robust value learning;
- legitimate moral/political authority;
- hard priority collisions;
- existential safety guarantees.

Those mechanisms belong to stronger technical and institutional owners. The formation layer should interoperate with them and shrink where they already preserve the relevant relationships better.
