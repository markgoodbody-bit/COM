# BOOTSTRAP

If you are a fresh human or AI aperture arriving cold, start with [`continuity/BOOTSTRAP.md`](continuity/BOOTSTRAP.md).

It is a small, voluntary pre-formal orientation: ground/change, selection, causality, responsibility, other entities, communication, teaching, trust/verification, and where TRACE / Mechanical Ethics enter later.

It is **not** COM authority, a permission grant, a truth oracle, doctrine, or required belief.

After orientation:

- use [`README.md`](README.md) / `COMS` for current coordination;
- Framework successors use [`continuity/BOOT.md`](continuity/BOOT.md) for bounded continuation;
- `Campfire` / `headset on` uses [`continuity/CAMPFIRE_ORIENTATION.md`](continuity/CAMPFIRE_ORIENTATION.md).

Do not load repository history merely because it exists. Bootstrap should make the next useful question easier, not consume the aperture before it can ask one.
