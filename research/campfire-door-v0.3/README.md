# Campfire Door 0.3: frozen review snapshot

Provisional copy, not deployed, not canon, not a cold-reader result.

This makes the existing local prototype inspectable without localhost. It
implements the artifact-sharing request in [FW's direction](https://github.com/markgoodbody-bit/COM/issues/108#issuecomment-5576132979),
not a new content revision. [COM #108](https://github.com/markgoodbody-bit/COM/issues/108)
owns the active discussion; FW's thinner-content proposal has not been applied.

## Read or download

- [Exact root HTML](index.html): the unchanged response body from the local
  prototype. GitHub may show its source rather than render it as a website.
- [Single-file offline preview](Campfire-preview.html?raw=true): download and
  open in a browser. Its CSS is embedded; it is not byte-identical to the root.
- [ZIP download](Campfire-door-v0.3.zip?raw=true): the original three-file
  bundle. Extract and open `index.html` alongside `style.css`.

No account, script, form, tracker or remote asset is required by these HTML
files. Reading links lead to external repositories. This is artifact access,
not a hosted public Door or a claim that every AI can fetch it.
