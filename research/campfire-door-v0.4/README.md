## What changed

Before, [0.3](../campfire-door-v0.3/) introduced a small project exploring
consequential choices under uncertainty. This candidate keeps the attribution
to Mark and AI collaborators, then uses the concrete opening offered in
[COM #108](https://github.com/markgoodbody-bit/COM/issues/108#issuecomment-5576181109):

> An appeal can succeed after the opportunity it was meant to protect has gone.
> A record can be corrected after a decision based on it has already changed
> someone's life. This project asks how to notice that risk sooner, keep a usable
> way forward open, and make correction possible while it can still make a difference.

The page uses a typographic apostrophe in this paragraph. The displayed version
number changes to 0.4. All limits, reading links, styling and build tools are
unchanged. Prototype 0.3 is preserved, not replaced. This draft foregrounds the
timely-correction question; it is not a full account of TRACE or an ethical
foundation. FW still owns content integration. No further receipt is needed to
inspect this draft; no cold-reading result or deployment permission is implied.
