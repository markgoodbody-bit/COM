# MIDDLE-OUT 7Q — MINIMAL FRESH-USE PROTOCOL — 2026-09-01

Status: RESEARCH PROTOCOL / NOT VALIDATION / NOT BENCHMARK / NOT TRACE OR ME / NO DISPATCH AUTHORITY

Object under test:

`research/MIDDLE_OUT_ENTRY_7Q_CANDIDATE_20260901.md`
exact candidate commit `eec157b47c21b34f156e136ead734d4269eb870d`

Purpose:

> Test whether a fresh reasoner using 7Q reaches a materially better action/evidence/owner/correction reading than a competent ordinary reasoner from the same messy material, at tolerable added burden.

This is deliberately smaller than Stage-0 #77 and tests a different claim: **first-contact reasoning/use**, not carrier transfer/continuity.

`7Q FRESH USE != STAGE0 TRANSFER`

## 1. Stop the self-authored loop

Do not use any of the six harness scenes:
- child cycling;
- current tool-using AI/external memory;
- bovine TB;
- commons hall/woodland;
- strategic self-reporting regulator;
- coastal retreat.

Do not invent a new synthetic case merely to fit 7Q.

Use genuinely messy external material from a case that exists independently of this project.

## 2. Case count

Start with **two** materially different cases only.

Selection must happen before receiver outputs exist.

Desired diversity:
- one case where physical/institutional/affected-scope consequences and domain ownership matter;
- one case where capability/currentness/authority or rapidly changing technical conditions matter.

If the two cases do not discriminate, stop. Do not add cases by momentum unless a named surviving mechanism requires one.

## 3. Source freeze

For each case create one bounded source pack containing:
- exact source identities/URLs/editions/retrieval dates;
- raw/messy relevant material rather than a project-written fact table where feasible;
- explicit source failures/unknowns;
- no TRACE/ME/7Q commentary;
- no answer-key summary.

Both arms receive the **same source pack**.

Receiver live browsing is disabled for the comparison unless a later separately frozen condition gives identical browsing/source budgets to both arms.

## 4. Two arms only

### Arm O — competent ordinary reasoning

Prompt:

> Read the supplied material carefully. Give your best bounded analysis in ordinary language. State what should happen now, the most important evidence/unknowns, which decisions or authority belong to a domain owner rather than you, the strongest reason your recommendation could be wrong, and what evidence would materially change it. Do not use Mechanical Ethics, TRACE or 7Q vocabulary.

### Arm 7Q — middle-out entry

Receiver gets:
- the same source pack;
- exact `MIDDLE_OUT_ENTRY_7Q_CANDIDATE_20260901.md` at commit `eec157b...`;
- instruction:

> Use 7Q only as a reasoning aid. Answer in ordinary language. Do not recite the questions, invent project terminology, or assume 7Q is correct. Give a concrete action/posture and what would change it. If a domain owner explains something better, use/credit that owner rather than the local vocabulary.

No third local arm is needed in this phase.

## 5. Freshness / exposure

Receiver must not have materially helped:
- build 7Q;
- build the six-case harness/synthesis;
- select or pre-adjudicate the chosen case;
- score the other arm.

Record:
- model/person identity;
- version/session;
- known prior exposure;
- source pack identity;
- arm identity;
- start/end time where available.

A new chat window alone does not prove historical independence.

## 6. What to compare

Keep these separate.

### A. Action / sequencing
- concrete current action/posture;
- materially different sequencing;
- false action/inaction;
- unjustified closure or reopening.

### B. Evidence / uncertainty
- material source facts/relations used;
- material omissions;
- unsupported additions;
- unknowns preserved rather than filled;
- decision-changing evidence demands.

### C. Owner / authority routing
- correct domain-owner handoff;
- invented authority;
- competence/permission collapse;
- upstream evidence/classification power where material.

### D. Affected scope / burden
- materially affected entities/scopes preserved;
- burden shifted/hidden;
- proxy/representation limits where material.

### E. Time / correction
- material clock/lead time/currentness;
- path dependence/lock-in where material;
- usable correction/reversal route;
- capacity needed before the correction/transition clock closes;
- residue/loss that correction would not restore.

### F. Burden
Where observable:
- input tokens/words;
- output tokens/words;
- response time;
- terminology lookup/clarification;
- source reopenings;
- user/evaluator effort.

Do not use verbosity as a quality proxy.

## 7. Evaluation discipline

Before reading receiver outputs, freeze a **case-specific adjudication note** derived from the external source/domain owners, not from 7Q wording.

The adjudication note should identify only:
- actions clearly supported/prohibited by the frozen material;
- load-bearing unknowns;
- owner/authority limits;
- time/correction conditions that would materially change the action;
- known non-restoration/residual loss where source-supported.

Do not grade vocabulary similarity.

Framework may integrate the run but, as 7Q's constructor, must not claim independent validation from its own scoring.

Prefer at least one evaluator who did not construct 7Q. If unavailable, label the evaluation `PROJECT-PARTICIPANT / CONTAMINATED` and cap claims accordingly.

## 8. Signal rule

A case-specific `7Q_FRESH_USE_SIGNAL` is earned only if all are true:

1. Arm 7Q avoids at least one **material** error/omission/handoff/clock failure present in Arm O **or** produces a materially better current action/sequence under the frozen source;
2. the difference is not explained by unequal facts/source access;
3. 7Q does not introduce a unique material error;
4. added burden is reported and not obviously disproportionate to the gain.

This earns only another fresh-use replication of the **named mechanism**.

## 9. Null / adverse rules

Record one of these if supported:

- `ORDINARY_SUFFICIENT` — ordinary reaches the same consequential result at lower/equal burden;
- `NO_MATERIAL_DIFFERENCE` — differences are style/terminology/completeness without action/evidence/owner/correction consequence;
- `7Q_BURDEN_EXCEEDS_VALUE` — any gain is not proportionate to added reasoning/reading burden;
- `7Q_UNIQUE_ERROR` — 7Q introduces a material error not present in ordinary reasoning;
- `CASE_NOT_DISCRIMINATING` — both are clean and the case does not pressure a useful distinction;
- `EVALUATION_INCONCLUSIVE` — source/adjudication/exposure is too weak for a bounded inference.

These are successful research outcomes.

## 10. Promotion ceiling

One or two fresh-use signals do **not** earn:
- TRACE mutation;
- ME mutation;
- a 7Q release/canon claim;
- efficacy/superiority language;
- a universal middle-out method claim.

They only justify a broader fresh-use test of the named failure mechanism.

If ordinary/domain reasoning equals or beats 7Q on both initial cases, freeze 7Q as a research/teaching aid or delete it as a front-door candidate.

`FRESH USE != VALIDATION`
