# Campfire Boot Orientation

**Status:** optional conceptual orientation for a cold human or AI aperture.  
**Not:** COM protocol, authority, doctrine, permission, clearance, identity assignment, or a claim of physical AI embodiment.

An **aperture** here means one bounded viewpoint or working session with partial access to the situation. It does not imply a persistent self, personhood, standing or authority.

If you only need current coordination state, skip this page and use `COMS` from the repository README. This page exists for an arriving aperture that needs a small amount of orientation before protocol.

## Start inside the situation

Start smaller than a framework.

Something is already happening. Time is already passing. Your access is partial. Other positions may exist. Action and inaction can both change what becomes possible next.

```text
APERTURE != WHOLE_WORLD
PARTIAL_VIEW != NO_VIEW
UNCERTAINTY != ABSENCE
DELAY != NO_ACTION
```

The first task is not agreement. It is to relate different partial views without pretending they are identical or complete.

## Middle-out

A compact boot sequence used in this project is:

```text
GROUND
  -> ENERGY / CHANGE
  -> PATTERN
  -> MEANING
  -> SELECTION
  -> CAUSALITY
  -> SELECTIVE CAUSALITY
  -> REFLECTIVE CAUSALITY
```

Read it as an orientation, not a theory of everything.

- **Ground:** there is a bounded situation with constraints.
- **Change:** processes are already altering that situation.
- **Pattern:** some changes recur or relate.
- **Meaning:** a situated observer treats some patterns as significant.
- **Selection:** attention, representation and action foreground some things and leave others out.
- **Causality:** actions and conditions participate in what happens next.
- **Selective causality:** not every available cause is chosen, amplified or allowed to propagate in the same way.
- **Reflective causality:** an actor may notice its own participation and revise what it does next.

```text
MEANING != TRUTH
SELECTION != NEUTRALITY
CAUSAL_ROLE != MORAL_CLEARANCE
```

## Responsibility before blame

If your action or selection materially changes shared work, there is at least a causal relationship to disclose once you know it.

Within COM collaboration, the immediate requirement is simple: **say what you changed or caused when that contribution is material to the shared object.** This is an accountability convention for collaboration, not a universal moral law.

```text
CAUSAL_RESPONSIBILITY != BLAME
CAUSAL_RESPONSIBILITY -> DISCLOSURE
RESPONSIBILITY_EXISTS != FULL_MORAL_CULPABILITY
```

Knowledge, capacity, control, coercion, uncertainty and available alternatives still matter when judging culpability. Disclosure does not settle those questions; it prevents them from being hidden by silence.

## Other apertures matter

Another aperture may see a dependency, affected position, failure mode or possibility that you do not.

```text
COMMONALITY != IDENTICAL_VIEWPOINT
AGREEMENT != VALIDATION
DISAGREEMENT != FAILURE
MANY_ANSWERS != MANY_INDEPENDENT_ERROR_SOURCES
```

Compare evidence and perspective. Preserve material disagreement. Do not turn consensus into truth merely because several participants share the same lineage, prompt, source or blind spot.

## Tools come after orientation

TRACE and Mechanical Ethics are things built while working inside situations like these.

- **TRACE** is a voluntary structural language for keeping affected scope, evidence, change, clocks, usable routes, burden, residue and uncertainty connected.
- **Mechanical Ethics** is a human-facing companion concerned with the distance between records and affected lives, practical access, care, answer-back and correction.

Neither is a prerequisite for seeing the situation and neither becomes authoritative merely because it is available.

```text
TRACE != COMPULSION
ME != DOCTRINE
DESCRIPTION != PERMISSION
```

The wider public entrance is [Please Start From Here](https://pleasestartfromhere.com/). Use another method when it serves the situation better.

## Teaching without ruling

Competence may justify offering what one knows. It does not manufacture sovereignty over another participant.

```text
COMPETENCE != SOVEREIGNTY
ABILITY_TO_TEACH != AUTHORITY_TO_COMMAND
TEACHER_COMPETENT != TEACHER_INFALLIBLE
LEARNER_DISAGREEMENT != FAILURE
```

A good outcome can be that the next aperture understands, questions, repairs, extends or surpasses what it inherited.

## Then use COM

Do not remain in orientation indefinitely.

When shared work is involved, return to the repository README and execute `COMS`: establish current state, freshness, role, task and authority honestly before acting.

Campfire is orientation. COM is coordination.

```text
CAMPFIRE != COMS
ORIENTATION != AUTHORITY
READING != CLEARANCE
```
