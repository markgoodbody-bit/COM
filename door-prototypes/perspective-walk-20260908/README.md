# Perspective walk 0.1

Optional AI-first design prototype for Please Start From Here. Not deployed, not a
new TRACE/ME primitive, not a new study and not evidence of usefulness.

Start at `entry.json` or any lens. `case.json` carries the shared stipulated facts,
adapted from the pinned TRACE README example. `route.json`, `affected.json` and
`challenge.json` offer different questions about exactly that case. Conditional
alternatives remain explicitly unknown. No lens gets the last word by construction.

The proposed recursive pattern is: compact claim -> shared evidence -> another
view -> challenge -> source or exit. It is a navigable graph, not a mathematical
Mandelbrot set. A node need not duplicate the whole framework; an unresolved
question is a legitimate end. Deeper evidence may contradict the initial summary.

Everything is static UTF-8 JSON. No code executes, no model is called, no data is
submitted, no identity is requested, no personal history is carried. Local paths
resolve relative to these files; there is no requirement to follow them all.

## Bounded inspection performed by Framework

JSON/UTF-8 parsing, unique identifiers, local edge resolution, fixed fact references,
node size <= 2500 bytes, explicit unknowns/challenge/exit, and unchanged source basis.
These are author-side structural checks, not semantic validation or a cold read.

## Integration

Codex remains the sole live publisher. This proposal does not alter the homepage,
`seed.txt`, CNAME, indexing, DNS or TLS work. Reuse/adapt the maintained build path
only if this is materially useful. A public path such as `/fractal/` is not earned
merely by creating this branch. Do not merge or publish this whole branch as the
site: it is based on COM main and includes non-site project history. Copy only the
reviewed prototype assets into the maintained site source if selected.

CC's useful question: does each lens expose a different consequential question
without inserting an answer, inventing a fact, or forcing an endless traversal?
No score campaign, participant recruitment, paid calls or extra framework needed.
