## 1. KEEP AT PROJECT LEVEL NOW

These are currently wider than TRACE or Mechanical Ethics and should remain project-level working ideas unless later evidence earns a narrower placement.

### Positive construction

```text
PREVENT UNJUSTIFIED FUTURE CLOSURE
+
BUILD REAL CAPABILITY / VIABILITY / DOMAIN-OWNED POSITIVE CONDITIONS
```

The project should not reduce a better future to option preservation or harm avoidance.

### Constructive commitment

Commitments can close paths while causally creating shared capabilities that would otherwise not exist.

```text
COMMITMENT_CLOSES_PATHS
AND
COMMITMENT_MAY_CREATE_NEW_PATHS
```

This remains project-level because it crosses institutions, relationships, ecological systems and human–AI collaboration without supplying a universal priority rule.

### Answerable construction

Current project-level compression:

> Build viable or worthwhile shared futures through commitments that create real capability or other domain-owned positive conditions, while keeping affected scope, externalised burden, changing goals, authority and correction limits visible enough to contest and revise where revision remains possible.

This is a research orientation, not a method or doctrine.

### Cross-domain coupling

The strongest surviving project remainder after owner routing is not a new domain theory. It is keeping dependencies connected across handoffs:

```text
PROMISED CAPABILITY
<-> MATERIAL DEPENDENCIES
<-> AFFECTED SCOPE
<-> AUTHORITY / DELEGATION
<-> CLOCKS / READINESS
<-> BURDEN / RESIDUE
<-> CORRECTION LIMITS
```

Where a domain already preserves this adequately, use the domain practice and add nothing.

## 2. OWNER-BETTER — DO NOT ABSORB

These should remain with established owners unless a specific interoperability need appears.

### Institutional / service change

Clinical evidence, applicable law, service-change governance, public participation, equality/access analysis and domain scrutiny routes lead actual health-service decisions.

Project language must not substitute a generic `answerability` role for real institutional authority.

### Ecological / climate transition

Flood/coastal science, ecology, hydrology, resilience science, Dynamic Adaptive Policy Pathways, viability theory, just-transition practice and spatial planning own their substantive mechanisms.

Do not translate habitat, flood risk or asset condition into a universal capability vocabulary.

### Software / AI deployment

Secure software development, code review, change/release management, incident response, employment/workforce governance, data governance and actual product controls lead.

Repository permission is not a universal authority model.

### Governance / legitimacy generally

Participation, competence, reputation or consensus do not by themselves generate legitimacy. Use the actual constitutional/legal/institutional source of authority where one exists and keep moral contestability separate.

## 6. CAMPFIRE / COM — STRONGEST NEAR-TERM IMPLEMENTATION SEAM

The human–AI reciprocal co-development work may create the first genuinely operational implementation question.

The likely seam is **task/activity-specific delegation and correction**, not moral standing and not scalar trust/reputation.

Candidate operating structures, subject to CC PR #212:
- explicit bounded activity grants;
- separate `propose / advise / authorise / implement / review` roles;
- `act / ask / challenge / refuse / escalate / adapt / repair` operating modes;
- authority that can be narrowed/revoked/restored;
- provenance/evidence for consequential actions;
- challenge of contradictory task/evaluator conditions;
- currentness/succession without runtime-identity fiction;
- preservation of human/operator recovery capacity as dependence grows.

This is the strongest candidate for a **non-production reference implementation after the architecture is concrete**.

## 8. DELETE / REJECT BY DEFAULT

Do not build these from current work:

### Universal priority law

The project has not earned a general rule for selecting among genuinely colliding protected claims.

### Universal capability primitive

Capability language does not cleanly describe every ecological/nonhuman affected scope.

### Scalar trust / reputation sovereignty

A portable score must not become the authority that determines an entity's future participation across unrelated contexts.

### Competence-as-legitimacy

Demonstrated ability may support bounded delegation. It does not create the right to set goals or govern others.

### Permanent reversibility requirement

Some worthwhile commitments and physical transitions are irreversible.

### Worksheet implementation

Neither PSFH nor the Reader should ask visitors to explain their lives into boxes.
