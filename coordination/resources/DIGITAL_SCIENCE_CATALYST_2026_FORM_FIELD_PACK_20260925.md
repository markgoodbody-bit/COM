## Short abstract — default (~80 words)

EvidenceWatch is a multi-step monitoring agent for living evidence-synthesis workflows. It watches sources already relied upon, suppresses unchanged or derivative repetition, preserves provenance and explicit source-authority boundaries, and routes material corrections or disagreements to downstream work that may need reopening. The current prototype is standalone with a CSL-JSON reference-manager handoff. The proposed pilot would test whether integrating this residual post-reliance monitoring into a real systematic-review workflow saves enough reviewer time, at acceptable error and maintenance cost, to be worth keeping.

## Short abstract — compact (~45 words)

## One-sentence problem

A research conclusion can remain unchanged after evidence it relies on has materially changed, while current tools already cover many formal retractions/corrections but not necessarily the full post-reliance workflow across heterogeneous sources.

## One-sentence solution

EvidenceWatch joins scheduled observation, duplicate suppression, bounded extraction, explicit authority, state comparison and dependency routing so a human sees which existing work may need another look without letting the agent rewrite scientific truth.
