## Stop rule

Stop accumulating nearby temporal cases by default.

Reopen the lane only if one of the following occurs:

1. **world falsifier** — a real case cannot be represented without adding/changing a materially action-relevant distinction;
2. **owner correction** — stronger literature materially changes one of the current compact distinctions;
3. **actual use** — a project/system needs the audit to make a real bounded decision;
4. **evidence opportunity** — funded/clean independent testing becomes feasible;
5. **source defect** — current TRACE/ME language is shown in use to hide or distort a temporal problem;
6. **novel domain pressure** — not merely another example of the existing chain.

Do not reopen merely because another delayed service, missed deadline or scheduling problem exists.
