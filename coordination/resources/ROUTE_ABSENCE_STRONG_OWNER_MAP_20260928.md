## 5. Transport / latent and suppressed demand

https://link.springer.com/article/10.1007/s43762-026-00276-3

## What survives owner subtraction

Not a new domain theory.

Not a universal metric.

Not a claim that every absent event represents a harmed person.

The small portable warning is:

~~~text
OBSERVED ENTRANTS
!=
ALL AFFECTED / INTENDED / NEEDING ENTITIES

FLOW AFTER ENTRY
!=
ACCESS BEFORE ENTRY

NO RECORDED REFUSAL
!=
NO FORECLOSED ROUTE

FORMAL ROUTE EXISTS
!=
SUBSTANTIVE ROUTE IS REACHABLE

DOWNSTREAM METRIC
CAN MISS
UPSTREAM NON-ENTRY / SUPPRESSED / RETURNED STATE
~~~

This may be useful as an **aperture check** when a system reports success or harm using only post-entry events.

## When the compression is worth using

Use only when all are plausible:
1. a consequential target route exists or should exist;
2. the observed metric begins after at least one gate/transition;
3. some affected entities can fail or self-select out before that observation point;
4. the omitted pre-entry state could materially change the interpretation;
5. the stronger domain owner has been checked first.

## Kill / stop conditions

Stop the project-native analysis when:
- the domain owner already measures the relevant unmet/latent/non-take-up population adequately;
- there is no evidence or credible mechanism for pre-entry omission;
- the proposed "missing door" is merely an imagined counterfactual;
- identifying the omitted route would not change any material decision;
- the project would have to invent a weaker parallel metric.
