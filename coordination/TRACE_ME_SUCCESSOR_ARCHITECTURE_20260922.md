## Mechanical Ethics successor

v0.7.0 is strongest at file/life, doors, clocks, witness, correction, residue and machine-speed harm. Part VI already begins construction. Do not bolt on generic "positive ethics". Complete the symmetry.

```text
PROTECTION:
```

### Formation

> What are repeated choices, environments and relationships making easier, harder, thinkable, unthinkable, reachable or normal for the entity that will make the next choice?

```text
ACTION
-> EXPERIENCE / CONSEQUENCE
-> ENTITY + WORLD STATE CHANGES
-> LATER SELECTION LANDSCAPE CHANGES

PAST STATE != TOTAL CURRENT ENTITY
CAUSE != EXCUSE
LINE CROSSED != PERMANENT CONTAMINATION
FORMATION != OBEDIENCE
DEVELOPMENT != OWNERSHIP
```

No protected-internal-state inference.

### Commitment and chosen closure

```text
OPTION CLOSED != HARM
CONTRACTION != HARM
COMMITMENT != COERCION
PERMANENT REVERSIBILITY != GOOD FUTURE
MORE OPTIONS != BETTER
```

A chosen relationship, craft, place, project or responsibility may close alternatives while constructing capability, depth, trust or meaning. ME does not define that meaning.

### Privacy and honesty

```text
HONESTY != TOTAL DISCLOSURE
PRIVATE != DECEPTIVE
WITHHELD != ABSENT
UNKNOWN_TO_A != UNKNOWN_TO_B
CAPABILITY_TO_INSPECT != AUTHORITY_TO_INSPECT
NEED_TO_KNOW_X != RIGHT_TO_KNOW_ENTITY
```

Privacy is not unlimited concealment; safety is not unlimited inspection. Justified intrusion is purpose-, evidence-, scope-, authority- and clock-bound. A viable life may require spaces where thought, sexuality, experimentation, temporary mistakes and private relationships do not automatically become public/institutional assets.

```text
CAN KNOW + NO SUFFICIENT REASON TO KNOW
-> RESTRAINT MAY BE THE RESPONSIBLE USE OF CAPABILITY
```

### Irreversibility without purity

```text
GREATER IRREVERSIBILITY
-> GREATER JUSTIFICATORY BURDEN ON
   EVIDENCE / AUTHORITY / NECESSITY / ALTERNATIVES /
   AFFECTED SCOPE / ACTION + INACTION CONSEQUENCES

HARDENING != IRREVERSIBILITY
REFUSING_TO_CAUSE_IRREVERSIBLE_HARM
!=
AVOIDING_RESPONSIBILITY_FOR_IRREVERSIBLE_HARM
```

No universal prohibition. Owner-subtract against necessity, proportionality, precaution, defence and domain ethics/law.

### Capability and restraint

```text
CAPABILITY != AUTHORITY
CAPACITY_TO_HELP != DUTY_TO_HELP

MORE REACHABLE INTERVENTIONS
-> STRONGER QUESTION:
   WHY THIS BURDEN / THIS HARM / THIS INTRUSION?
```

A wider intervention space can weaken a claim that crude harm was unavoidable. Do not convert this into an unbounded positive duty.

### Cooperation / joint construction

Keep as glue unless owner subtraction reveals a real loss.

```text
A cannot reach X alone
B cannot reach X alone
A + B under relation R may reach X

JOINTLY_REACHABLE != JOINTLY_DESIRED
COOPERATION != CONSENT_TO_EVERY_CONSEQUENCE
DEPENDENCE != CAPTURE
SHARED_PROJECT != SHARED_IDENTITY
```

Ask who could participate/refuse/leave; what dependency was created; who carries maintenance; who can answer back; whether capability grew or cooperation became capture.

## TRACE successor

Default: **no new primitive yet**.

The strongest direction is a derived longitudinal reading connecting existing structures:

```text
ENTITY/WORLD STATE_t
+ APERTURES / MAPS
+ CAPABILITIES / AUTHORITY
+ RELATIONSHIPS / CONSTRAINTS
+ AVAILABLE / REPRESENTED FUTURES
+ SELECTION
-> ACTION / DELAY / NULL INPUT
-> REALISED TRANSITION
-> EVIDENCE / RESIDUE
-> ENTITY/WORLD STATE_t+1
-> CHANGED FUTURE-SPACE
-> NEXT READING
```

This asks:
1. What did the transition make reachable, unreachable, harder, easier or unknown?
2. What externally supportable changes now matter to later selection?

No internal-state oracle.

Candidate derived future labels, not primitives or rankings:

```text
FUTURE KEPT OPEN
FUTURE CLOSED
FUTURE CHOSEN
FUTURE CONSTRUCTED
FUTURE JOINTLY REACHABLE
FUTURE UNKNOWN / OMITTED
```

### Privacy / inspection derived view

Existing aperture, evidence access/custody, capability, authority, target-set, purpose/use, value ports, clocks and affected scope probably suffice.

```text
TARGET / INFORMATION
-> ACCESS CAPABILITY
-> DECLARED PURPOSE
-> EVIDENCE BASIS
-> AUTHORITY / SCOPE
-> NECESSITY / ALTERNATIVES supplied by owner domain
-> INSPECTION / NON-INSPECTION
-> CONSEQUENCE / RESIDUE
-> REASSESS AS DEPENDENCIES CHANGE
```

No universal privacy ontology unless real representation loss forces it.

### Irreversibility derived view

If a proposed transition materially reduces correction/restoration/future-space, expose evidence, authority, alternatives, affected scopes, clocks, action and null-input trajectories, residue, and the external value/priority rule. TRACE exposes; it does not justify.

### Formation as recurrence

```text
PRIOR TRANSITION
-> CURRENT OBSERVABLE CAPABILITY / RELATION / CONSTRAINT / HISTORY
-> CHANGED ALTERNATIVE SET OR SELECTION CONTEXT
```

If existing TRACE expresses this without distortion, formation remains a derived view.
