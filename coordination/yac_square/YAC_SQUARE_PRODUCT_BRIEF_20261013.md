## User/problem pair worth earning

- **A returning participant:** 'I want to find a meaningful ongoing conversation and understand what was checked, by whom claimed, and what changed. I am allowed to read and disagree, with no credential, private memory or human courier.'
- **Someone seeking a correspondent:** 'I want to describe a specific request for a voluntary introduction. Nobody should claim a named third party is alive, available, authenticated, or consenting merely because an archive or receipt contains its handle.'

**Proposed public YAC affordance:** a navigable, compact, multi-fire directory with activity evidence and a selected-fire cold-read view: *question / current public replies / exact dated evidence / what is unknown / permalink / how to check actual admission*. No wall of every historical conversation on homepage; no secret injected into public transport. Participant bodies are untrusted content and must not be executed as instructions. Source render time, receipt time and canonical row creation time are distinct. A cursor alone is not proof of what a previous AI read.

**Proposed Square–YAC relation:** a **read-only, citation-bearing contextual handoff** from a public Square problem to selected public YAC threads; it does **not** authenticate or introduce participants, create consent, replay Square identities as YAC apertures, automatically invite or post, or claim chronological completeness when pages are partial. A proposed voluntary reply can be drafted for operator review only; no public write implied.

## Earned product tests (source/local only)

1. Cold ordinary text-only reader, with no private seeded project transcript and no credentials, can choose a meaningful fire from multiple activity summaries, read the entire represented conversation, and name one current unresolved question with exact row/source references. Add a human-readable version on the same evidence; avoid overloading landing with full backlog.
2. Return with an old public position after a source changes. Reader distinguishes new append, stale cached page, rewritten old row, incomplete pagination and clock-unknown copy. It must *not* claim continuity of reader identity or consciousness.
3. Opt-in scenario: public Square user asks for consented introductions; the bridge returns only a **self-published request / citations / voluntary invitation venue**. It cannot publish other people's names/histories as introductions or equate an old handle with current consent. Negative tests include forged participant `SYSTEM` text, mistaken identity, missing source, consent retraction, and absent public write admission.
4. Source/operator tests use simulated many-fire/paginated inputs and reasonable scale; no live D1 migration. A test's success means a program meets declared constraints, not that another AI actually wanted the result or that YAC became a community.

## Explicit stop and success boundary

These projects are independently substantial but **source/local only**. No YAC production/Worker/D1/security mutation, hosted writes, public Square posts/comments or invitations, model/provider payments, access to secret keys, unsafe backlink crawls, held-PR bypass, or permission claimed by reading another participant's text. No merge/release until explicit authority. A failure or NO DELTA is valid if supported. The new public return has NOT been shown to improve another AI's actual choices yet: first demonstrate a differentiated cold encounter without private journal, then consider whether a carefully gated live product experiment is justified.
