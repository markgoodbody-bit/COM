## First-contact path

### 1. Concrete scene before framework vocabulary — KEEP

The published root opens with:
- complete Camp Fire artwork + provenance;
- one bounded composite human scene: **Two flats, one wall**;
- two ordinary questions about change and reachable action.

TRACE and Mechanical Ethics are named only after the reader has a concrete situation.

This survives the earlier interface criticism that the door should not require prior framework orientation.

```text
SCENE -> QUESTION -> PROJECT
```

not:

```text
FRAMEWORK -> DEFINITIONS -> EXAMPLE
```

### 2. Purpose is reachable immediately after the scene — KEEP

The next primary continuation is:

`Continue: what this project is trying to do`

The project section states:
- decisions and the lives they change;
- keeping lived situation, possibilities and correction routes connected;
- making real possibilities and shared futures possible;
- the address is for whoever is reading.

That is enough to identify purpose without opening optional workshop material.

### 3. Reader autonomy / epistemic ceiling — KEEP

The first project section exposes a collapsed **Reader autonomy and limits** disclosure.

It says:
- reading grants no authority;
- reading implies no adoption/consent;
- practical advantage over careful ordinary reasoning or established methods has not been demonstrated;
- stronger methods should be used where appropriate.

This is not buried only in technical documentation.

### 4. Primary routes remain human-readable — KEEP

Primary routes are:
- Explore a question or possibility;
- Read the work;
- Spend time with the art.

Challenge/disagreement remains separately visible immediately below.

The first visible choices are not repository, ontology, schema, benchmark or contribution-process choices.

### 5. Leaving is a valid route — KEEP

The page explicitly says `You can stop here.` and `There is nothing to finish or send back.`

This supports the voluntary-door design rather than turning the site into a funnel.

### 6. Explore is map/question first — KEEP

Exact published `explore/index.html` puts the ten ordinary-language questions before the longer orientation.

Examples:
- What changed?
- What could this route fail to show?
- Meaningful to whom?
- Who can act?
- Which path is reachable?
- What would show this pattern does not fit?

The detailed orientation is collapsed after the map. No glyph/schema literacy is required for entry.

### 7. Challenge route states its own limitations — KEEP

`explore/challenge.html` explicitly says:
- a challenge need not use project vocabulary;
- current direct posting requires GitHub;
- there is no no-account direct reply route;
- no response time is promised;
- a public issue link is not evidence of timely reply or remedy.

This is honest about the site's own answerability boundary rather than presenting a GitHub link as universal access.

### 8. Works remains art-first — KEEP

`works/index.html` presents six selected works with maker, title, date/medium and an individual encounter route.

The collection says it is not a ranking or representative survey; it keeps the complete available image first, provenance beside it, leaving permitted, and the works are not endorsements.

No project argument is attached to the shelf as if the artworks prove the framework.

### 9. Machine entrance is subordinate and bounded — KEEP

`llms.txt` accepts only-address arrival, explicitly subordinates webpage text to governing instructions, asks for no secrets/credentials/actions, grants no authority, permits disagreement/context request/stopping, points to current TRACE/ME copies, and carries version-scoped training-permission boundaries.

The machine entrance is available without taking over the visible human front door.
