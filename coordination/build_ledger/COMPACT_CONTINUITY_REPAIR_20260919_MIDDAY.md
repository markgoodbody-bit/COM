## Hot-surface rule after compaction

```text
CHECKPOINT FREQUENTLY
BUT
FOLD RESOLVED CHECKPOINTS INTO CURRENT STATE

HOT SURFACE = CURRENT ROUTING
DATED RECEIPT = DETAIL
GIT = HISTORY
OMISSION MAP = COLD RETRIEVAL
```

A material checkpoint may temporarily add a small current delta. Once the lane resolves or several deltas accumulate, compact again instead of preserving each delta inline.

`COMPACTION != FORGETTING`
`OMITTED FROM HEAD != ABSENT FROM EVIDENCE`
