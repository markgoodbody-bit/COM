## Strong owner discovery

A fresh owner search found that the generic product object is already substantially built elsewhere.

### Doubt

Owner:
https://github.com/alsoleg89/doubt

Current public product already provides:
- zero-dependency CLI + Agent Skill;
- atomic claims, sourced observations and explicit unknowns;
- typed support / contradiction / qualification / missing edges;
- bounded source regions and retrieval dates;
- fail-closed deterministic validator;
- self-contained interactive HTML;
- SHA-256 evidence receipts;
- explicit rejection of unsupported confidence percentages;
- an evidence ladder that asks whether corroborating evidence is independent or copied from another source;
- an adversarial evidence-contract benchmark;
- a preregistered map-vs-cited-memo reader study.

Its public schema does not expose source ancestry as a dedicated source-to-source field, but the workflow already requires independence checking and can represent ancestry/dependence as ordinary sourced claims/qualifications.

## Disposition
