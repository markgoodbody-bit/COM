## New owner lessons

Deeper work added four useful corrections.

### 1. Non-normative time is not automatically a deficit

Crip-time / disability-studies work warns against treating slower, uncertain or differently patterned temporalities as mere failure against a normal clock.

Preserve:

```text
DIFFERENT RHYTHM != DEFICIT
SLOWER != WORSE BY DEFAULT
ACCESS != MAKING THE PERSON MATCH THE INSTITUTION
```

### 2. Flexibility can be one-sided

Work-schedule research shows that organisational flexibility / just-in-time scheduling can transfer unpredictability and coordination burden onto workers.

```text
OPERATOR FLEXIBILITY
!=
AFFECTED-PERSON TEMPORAL AGENCY
```

### 3. Recovery is functional capacity

Rest/recovery and disability-temporality work support:

```text
NO SCHEDULED TASK
!=
AVAILABLE CAPACITY

REST
!=
WASTED TIME
```

### 4. Individual accommodation is not the whole of access

Margaret Price's work on Crip Spacetime / accompaniment / collective accountability challenges access systems that repeatedly require the individual to ask, explain and carry the exception process.

```text
INDIVIDUAL ACCOMMODATION ROUTE
!=
ACCESSIBLE ENVIRONMENT
```

## Design pattern library

Added:
`coordination/resources/TEMPORAL_EMPATHY_DESIGN_PATTERNS_20260927.md`

Patterns include:
- represent uncertainty honestly;
- advance notice / schedule predictability;
- explicit next-check time;
- reminder / intention offloading;
- count work created by the remedy;
- subtract before adding;
- protect recovery;
- protect critical phases from non-urgent interruption;
- affected-person control over deferral;
- pause/toll the institution's clock where domain-appropriate;
- show waiting as a consequential state;
- track temporal burden transfers;
- accompaniment / collective access;
- preserve humane slack;
- separate throughput targets from human temporal value.

These are owner-routed intervention families, not prescriptions.
