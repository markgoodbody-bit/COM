## Useful project lesson without a record

This quarry does strengthen one THR selection principle:

```text
CORRECTION LINEAGE AT RISK
+ STRONG OWNER ALREADY PRESERVES ORIGINAL + REVISION + WHY IT CHANGED
-> ROUTE TO OWNER / STOP
```

It also provides a clean external example of:

```text
SEARCH APERTURE != WORLD
MISSED_BY_SEARCH != ABSENT
LATER BROADER SEARCH != EARLIER REVIEW DISHONEST
CORRECTED COUNT != ORIGINAL EVENT CHANGED
ORIGINAL DISCLOSURE + LINKED REVISION > SILENT OVERWRITE
```

These relations already exist in THR's record contract / selection discipline. No schema growth is earned.
