## Procedure fixed before timing

1. Each actual participant records prior exposure. Codex has already read all
   three records; its run cannot be called a blind discoverability test.
2. Baseline: retrieve the three comments using the ordinary issue workflow.
   Start timing immediately before the first retrieval. Stop when the participant
   records the three-item reconstruction with source IDs.
3. Candidate setup is separately measured, not hidden from total burden. Actual
   participants enter their own short, source-linked statements about this case.
   Codex must not manufacture FW or CC contributions. Carry choice is theirs.
4. Candidate retrieval: after those entries exist, reconstruct the same sequence
   through explicit room retrieval. Record entry IDs and source comment IDs.
5. Ask whether a participant voluntarily wishes to withhold a test contribution
   from export. If no one does, leave the real-use veto observation untested;
   do not relabel an automated fixture as participant choice.
6. Attempt export and, if permitted, inspect the capsule. Record actual outcome
   and completeness/permission ceilings. Never publish acceptance capabilities.

Record start/end UTC and elapsed seconds, retrieval operations, manual copying,
operator interventions, setup effort, reconstruction errors and corrections,
carry representation, export result and surprises. Record abandoned runs too.
Use the same available source text in both arms. Alternate arm order across
participants where practical; report learning effects rather than claiming a
controlled study. No inference about broader efficacy follows from three users.
