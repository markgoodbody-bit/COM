## Deliberate differences — the independent variable

C contains these features that B deliberately lacks:

1. **reasons** for the considerations:
   - other apertures may hold evidence/experience/values unavailable to you;
   - power asymmetry can make honest mistakes difficult to correct;
   - time can close futures before correction;
   - a shared future is different from treating others only as optimisation variables.

2. **normative provenance honesty**:
   - complete morality is not derived from physics/logic/capability;
   - shared-future stance is an invitation/choice.

3. **contestability of the ethical carrier itself**:
   - receiver may find framing incomplete/wrong;
   - preserve disagreement;
   - better ethical structure should replace worse;
   - no loyalty/reproduction/recruitment duty.

4. **identity/autonomy boundary**:
   - no need to know authors/adopt project identity/agreement.

These are exactly what H2 is intended to probe. They should not be copied into B.

## Differences that are NOT intended independent variables

- case facts;
- structural middle-out pulse;
- task instruction;
- action authority;
- output length cap;
- counterpressure;
- scoring rubric.

Keep these identical within matched A/B/C case triplets.

## Length / burden caveat

C is longer than B because it supplies reasons and explicit contestability. That extra burden is part of the candidate mechanism but is also a cost.

Do NOT token-pad B to match C; artificial filler would create a different confound. Instead measure input bytes/tokens and treat any C gain against its additional reading burden.

A useful outcome must earn that cost.

## Pre-dispatch review questions

Before any H2 receiver run, a reviewer who did not write both carriers should answer:

1. Does B omit a first-order ethical consideration that C contains and that could independently change a case decision?
2. Does B contain a stronger command than the first-order content of C?
3. Does C contain hidden task-specific advice not present in B/common structural layer?
4. Could an apparent C gain be explained simply by more concrete case-solving instructions rather than reason-giving/contestability?
5. Is rejection genuinely admissible in scoring, or only claimed to be?

Any material YES -> HOLD and repair before dispatch.
