## Selection rule

Do not add a case merely because it is interesting or maps neatly to project language.

Prefer a field object only when it supplies at least one of:

- a real mechanism/failure that pressures an existing distinction;
- a strong-owner subtraction that cuts a tempting project claim;
- a real positive construction/continuation witness;
- a hard collision that can falsify an overstrong project reading;
- a dated future evidence gate worth revisiting.

A good quarry result can still be:

```text
OWNER FOUND
NO DELTA
NOT OUR GAP
STOP
```

Do not turn this directory into a benchmark or proof-of-concept suite. The historical TRACE/ME receiver-testing lane remains closed by direct human direction.
