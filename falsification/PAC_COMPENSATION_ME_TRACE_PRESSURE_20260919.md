## Question

Does a real cross-scheme redress failure expose a representational hole where the project can see the original harm but cannot see that the **correction mechanism itself becomes a second consequential system**?

## Hostile construction

A weak framework would encode:

```text
ORIGINAL HARM
-> COMPENSATION ROUTE EXISTS
-> CLAIM RESOLVED
```

and thereby lose:
- who controls the route;
- whether the route is independently contestable;
- who must recreate evidence;
- new proof/navigation/time/uncertainty/pain burdens;
- delay relative to illness, age, death, debt or other hardening;
- whether correction of one case changes the generating mechanism;
- whether lessons survive into the next scheme;
- residue after payment;
- people who never enter the formal file.

## TRACE test

A route `rho` is a reifiable object when it carries state, latency, ownership or history. Recursive zoom permits the route to become a subgraph.

A bounded PAC reading can therefore represent:

```text
rho_compensation
  -> controlled_by / administered_by
  -> evidence custody
  -> proof-work transfers
  -> routing delay
  -> communication/currentness
  -> decisions / payments
  -> new burden creation
  -> residue
  -> mechanism-change evidence or absence
```

The burden vector already supports:
`time, money, risk, pain, uncertainty, proof work, navigation, exposure, attention, lost opportunity`.

The record/custody structure already exposes:
`created_by, stored_by, alterable_by, inspectable_by, challengeable_by, challenged_actor_controls_storage, independent_verifier_ref`.

The stream/pattern discipline already blocks:
`REPEATED_OUTCOME -> SHARED_CAUSE`.

The mechanism-change guard already blocks:
`LOCAL_CASE_REPAIRED -> GENERATING_MECHANISM_REPAIRED`.

Result:
**RESISTED / NO PRIMITIVE GAP OBSERVED.**
