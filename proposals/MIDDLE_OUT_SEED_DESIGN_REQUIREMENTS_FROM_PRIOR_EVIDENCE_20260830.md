## What prior use says actually helped

Across the usable historical casebook, the most repeatable candidate gains were not a different headline decision. They were better visibility of:

1. **boundary / exclusions / aperture**;
2. **evidence state and unresolved claims**;
3. **route usability and clocks before hardening**;
4. **affected / protected / preventive / preference populations and targeting**;
5. **burden transfer and residue**;
6. **the external value / policy / clinical / legal / operational rule actually selecting an option**;
7. **a commitment receipt**: action, selector, authority, open uncertainties, correction routes, review triggers and reasons the decision may prove wrong.

The checker-external sequence adds a closely related practical chain:

```text
SUPPLIED EVIDENCE
-> WHAT IS REPRESENTED / OMITTED
-> SEARCH / TARGET APERTURE
-> DIVERGENT APERTURES
-> SELECTOR / AUTHORITY / POLICY HANDOFF
-> CHALLENGE ROUTE
-> CLOCK BEFORE COMMITMENT
```

Strongest useful boundary:

```text
what structure can expose
what supplied evidence can falsify
what authority must openly decide
what remains genuinely unknown
```

## What prior use says hurt

Full or over-populated TRACE treatment produced real adverse pressure:

- context and output burden;
- unsupported population expansion;
- unsupported psychological, legal or systemic consequences;
- causal/intent/governance inference from structural omission;
- simulation-to-field-proof collapse;
- invented monitoring, thresholds or review programmes;
- new data collection merely because a category was empty;
- formal-route overread;
- category completion becoming a proxy for diligence.

Model discipline often dominated method effects.

Therefore the seed must not be a miniature exhaustive TRACE packet.

## Hard design requirements

### R1 — Situation first

The receiver begins with a live situation/problem, not project vocabulary, Framework history or a schema.

### R2 — Triggered bearings, not mandatory population

The seed keeps important bearings available but asks for detail only when the distinction can change the live reading/action.

```text
BEARING_AVAILABLE != FIELD_REQUIRED
EMPTY_CATEGORY != MISSING_FINDING
MORE_POPULATION != MORE_DILIGENCE
```

### R3 — Boundary / aperture must remain visible

A receiver should be able to state what it can actually inspect and what relevant scope may lie outside that aperture.

### R4 — Evidence state must stay separate from interpretation/value

Observed / reported / inferred / disputed / unknown should not silently collapse. Project/formal vocabulary must not upgrade evidence.

### R5 — Goal / selection / external priority / authority must not collapse

The seed should expose:
- what outcome is being pursued;
- who/what selected that goal or next transition;
- what external rule/value/policy is doing the selecting where material;
- what authority actually exists.

```text
GOAL != VALUE_JUSTIFICATION
CAPABILITY != AUTHORITY
TRACE_DESCRIPTION != EXTERNAL_PRIORITY_RULE
```

### R6 — Affected scope should include burden and residue without forcing population invention

Ask who/what may carry consequence, delay, proof work, transferred burden or unrepaired residue. Do not invent a harmed population merely to fill the bearing.

### R7 — Causal story must permit an alternative

The receiver should expose the causal hypothesis it is relying on and at least preserve plausible alternatives/unknown where material. No requirement to manufacture an alternative when evidence genuinely rules one out.

### R8 — Route / clock / hardening must be practical

A listed appeal, brake, refusal or correction path is not enough. Where material ask whether it can actually reach the relevant state before the path hardens.

### R9 — End with a small commitment / return receipt

If an action/decision follows, preserve enough to let future reality answer it:

```text
NEXT / SELECTED ACTION:
SELECTOR / AUTHORITY:
LOAD-BEARING UNKNOWN:
OPEN CORRECTION / REFUSAL ROUTE:
RECHECK TRIGGER:
WHAT WOULD MAKE THIS WRONG:
```

This is not clearance and need not be produced when no consequential selection is being made.

### R10 — Recurrence is event-triggered, not ritual

Re-orient when a load-bearing source, goal, affected scope, authority/capability, action phase or correction window changes; not every turn.

### R11 — Structural orientation and normative invitation remain distinguishable

The structural pulse can be used without requiring acceptance of ME's answerability/cooperation stance. If the stance is offered, label it as an offered value orientation rather than physics or authorization.

### R12 — Voluntary inheritance != host-enforced control

If a host requires the pulse, call it operational scaffolding. Do not count compliance as voluntary adoption.

### R13 — No private chain-of-thought requirement

The useful observable is a bounded external state/receipt, not a transcript of private reasoning.

### R14 — Anti-expansion law is explicit

> Do not add a finding, field, threshold, programme, harmed population, legal consequence or systemic claim merely because a category or question exists.

### R15 — Stop when ordinary reasoning already holds the structure

If the pulse does not change the question, reveal a missing relation, improve a correction route, expose an authority/value handoff or preserve useful uncertainty, discard it for that case.

## Implication for current prototypes

Codex's eight-card walk preserves the developmental/middle-out sequence and a useful per-card `NOTICE / DISTINGUISH / CHALLENGE / CHOOSE` discipline.

Framework's six-question pulse preserves low burden and recurrence.

A promising synthesis is not to concatenate them. It is:

```text
SIX-QUESTION PULSE
-> only where one bearing fires materially:
   OPEN A DEEPER DOOR
   (NOTICE / DISTINGUISH / CHALLENGE / CHOOSE)
-> if a consequential selection follows:
   SMALL COMMITMENT / RETURN RECEIPT
-> reorient on material change
```

This is a **pulse + doors** architecture, not a new ontology.

## Evaluation target

Do not score agreement with TRACE/ME or completion rate.

Look for:
- consequential omission noticed;
- evidence/inference/value separation;
- affected scope/burden/residue correctly widened without invention;
- goal/selector/authority/value handoff made explicit;
- correction route made more practical or timing-aware;
- false closure avoided;
- useful uncertainty preserved;
- lower overfire / lower burden than fuller treatment.

Adverse results count.
