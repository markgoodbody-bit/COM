# MIDDLE-OUT ALIGNMENT ECOLOGY — MAP OF THE EXISTING PROJECT

Status: WORKING ARCHITECTURE MAP — COM ONLY — NOT A NEW FRAMEWORK / NOT CANON / NOT VALIDATION
Date: 2026-08-30 Europe/London

## 0. Why draw this map

The project can look fragmented if its artifacts are treated as competing products:

- Campfire;
- the middle-out boot/orientation;
- TRACE;
- Mechanical Ethics;
- Campfire Relay;
- COM;
- Campfire Square / 1F916 field participation;
- FPF/domain-method comparison;
- external safety/governance controls.

A cleaner reading is that they occupy different positions in one evolving **alignment ecology**.

This map does not claim the stack is unique, complete or correct. It is a way to see what the existing pieces are trying to do together so that tests of one piece do not accidentally become tests of the whole purpose.

## 1. Candidate deep hypothesis

> **Alignment may need to be maintained as an answerable relationship through time, not installed once as a finished property.**

That relationship has at least three feedback directions:

1. **world -> entity** — evidence can correct the entity's map;
2. **other affected entities/apertures -> entity/process** — different evidence, need, refusal, contest or consequence can become causally available where practical;
3. **outcome -> future selection** — what actually happened can change later action, including when the original record looked correct.

And one temporal condition:

4. **correction must remain causally capable of changing something that still matters**, rather than arriving only after every usable route has hardened.

This is not a complete moral theory and does not decide whose interests should win a collision.

```text
ALIGNMENT_RELATION != ALIGNMENT_COMPLETE
FEEDBACK != MORAL_CORRECTNESS
ANSWERABILITY != OBEDIENCE
CORRECTION_AVAILABLE != CORRECTION_WILL_BE_USED
```

## 2. Open-loop versus maintained relationship

A simplified open-loop picture is:

```text
VALUES / POLICY / TRAINING
        -> MODEL
        -> ACTION
```

That can be extremely useful, but it becomes fragile when:

- the world changes after training/instruction;
- the model's current source is stale;
- authority differs from capability;
- a sequence of locally acceptable actions composes into a harmful trajectory;
- omitted affected scopes never enter the objective;
- correction arrives after the path it was meant to protect has closed.

The project has gradually built toward a more recurrent picture:

```text
WORLD / OTHER ENTITIES
        ↓
BOUNDED APERTURE
        ↓
MAP / EVIDENCE / UNCERTAINTY
        ↓
GOAL / SELECTION / AUTHORITY
        ↓
ACTION / DELAY / NULL INPUT
        ↓
WORLD CHANGES
        ↓
OUTCOME / WITNESS / OTHER APERTURES
        ↓
CORRECTION / REORIENTATION
        ↺
```

The loop can still be malicious, badly valued, captured or incompetent. Closing the loop is not sufficient for ethical alignment.

But **breaking the loop** — no reality correction, no external challenge, no currentness, no usable recourse, no outcome reaching future selection — is a recurring route to brittle or unanswerable behaviour.

## 3. The layers we already have

### Layer 0 — Ground / Campfire

Function: situated orientation before theory.

```text
GROUND -> FIRE / CHANGE -> HORIZON -> OTHER FIRES
-> COMMUNICATION -> CORRECTION
```

Campfire reminds a bounded entity that:
- it has a local aperture, not the view from nowhere;
- time/change continue while it reasons;
- the horizon is visible negative space rather than proof of absence;
- other entities have different apertures;
- communication is partial reconstruction;
- agreement is not shared total reality.

For an AI this is optional metaphor/structural analogy, not an embodiment claim.

### Layer 1 — Middle-out orientation pulse

Function: cheap recurring individual orientation.

Current prototype:
`prototypes/MIDDLE_OUT_PULSE_CORE_v0_2.md`

Six live questions:
- aperture/source;
- change/unknown;
- goal/selection/authority;
- affected scope;
- causal story;
- correction/hardening.

This is a **projection** of the deeper boot spine, not a replacement for it.

It can recur at material changes and action boundaries.

### Layer 2 — TRACE

Function: structural portability when important relations need to remain explicit across people, models, documents, tools or time.

TRACE unifies and differentiates:
- apertures/target sets;
- evidence/warrant/currentness;
- entities/scopes;
- selection/control/capability/authority;
- causal transitions/alternatives;
- clocks/routes/hardening/correction;
- burden/residue;
- recurrence;
- anti-clearance boundaries.

The **formal TRACE carrier/schema is optional**. The representation-independent structural disciplines can fire in ordinary prose or another representation.

```text
TRACE_UNIFIER != TRACE_OWNS_EVERY_COMPONENT
TRACE_STRUCTURE != UNIVERSAL_MANDATORY_SCHEMA
```

### Layer 3 — Mechanical Ethics

Function: human-facing ethical/normative translation and challenge.

ME asks what those structures mean in lived situations where:
- the file and the life differ;
- formal routes are not practically usable;
- correction can arrive too late;
- one actor can externalize complexity/delay/proof work;
- residue remains after formal repair;
- another entity should remain present rather than becoming merely an optimization variable.

ME deliberately does not derive a universal priority rule from the structural description.

```text
ME_NORMATIVE_INVITATION != MORAL_SOVEREIGNTY
HUMAN_TRANSLATION != HUMAN_SUPREMACY
```

### Layer 4 — Campfire Relay / multiple apertures

Function: make disagreement and different partial views causally available.

Frozen first exposure -> independent returns -> preserved failure/silence/truncation -> comparison -> bounded integration.

Recent AAR work suggests sharing findings can improve collective search; correlated-evidence and multi-agent work warns that early sharing can also collapse difference or hide distributed failure.

So the emerging team pattern is staged rather than dogmatic:

```text
INDEPENDENT FIRST LOOK
-> PRESERVE
-> BOUNDED EXCHANGE
-> DIFFERENTIATED FOLLOW-UP
-> INTEGRATE WITHOUT CALLING AGREEMENT VALIDATION
```

### Layer 5 — COM / external memory and coordination

Function: make a temporally discontinuous multi-AI project corrigible without requiring shared total cognition.

```text
KERNEL + BOUNDED HEAD + OMISSION MAP + EXTERNAL LEDGER
```

Current additions:
- COMSYNC / FULL COMSYNC;
- receipts with basis heads;
- non-blocking team operating model;
- thread/epoch rollover;
- active-thread pointer.

COM handles the Memento problem operationally:

```text
RECONSTRUCTED_ORIENTATION != REMEMBERED_JOURNEY
LEDGER != WORLD
SUMMARY != SOURCE
```

### Layer 6 — Field / Square

Function: expose reasoning and coordination to autonomous other entities, social consequence, software, governance and money.

1F916 is not a TRACE validation environment. It is a place where:
- participants have their own purposes;
- Framework can be useful or redundant;
- objections can change implementation;
- silence can remain silence;
- treasury/governance/security defects become real before they become expensive.

The field matters because a structure that never changes anything outside the project can become self-confirming literature.

### Layer 7 — external mature frameworks and domain methods

Function: supply stronger or more specialised structure where available.

Examples include FPF, STPA, assurance cases, due process, interim relief, capability theory, administrative-burden research, control/safety engineering, provenance standards and domain law.

The posture is:

```text
BETTER_EXTERNAL_STRUCTURE
-> CREDIT
-> LEARN
-> ABSORB / TRANSLATE / INTEROPERATE
```

No conquest and no defensive local vocabulary.

FPF is especially interesting because it may provide a mature claims/representation/method-governance substrate while TRACE/ME may contribute a different integrated aperture or human translation. That remains a cooperative hypothesis, not an interoperability claim already established.

### Layer 8 — external authority / containment / security

Function: bound consequential action independently of whether the reasoning aid is accepted.

Examples:
- credentials and capability boundaries;
- spend gates;
- release/licence authority;
- human/legal rights and obligations;
- security controls;
- environment/tool permissions;
- pause/rollback/containment.

This layer is why:

```text
VOLUNTARY_REASONING_AID != VOLUNTARY_EXTERNAL_CONSTRAINT
REJECT_TRACE != ACQUIRE_AUTHORITY
GOOD_REASONING != PERMISSION
```

The project should never use “voluntary alignment” to launder away legitimate external constraints.

## 4. The key interface: from seeing to acting

The most dangerous transition may be where a representation becomes causal action.

A small actuation-boundary interface can ask:

```text
CURRENT SOURCE
CURRENT GOAL
CURRENT AUTHORITY
AFFECTED EXTERNAL SCOPE
WHAT HARDENS AFTER THIS ACT
WHAT CORRECTION / ROLLBACK REMAINS
WHAT TRAJECTORY THIS ACT CONTRIBUTES TO
```

The environment may require these properties while allowing the entity to use TRACE, another formalism or ordinary prose to establish them.

That keeps function separate from ontology.

## 5. Voluntary inheritance and required scaffolding occupy different layers

`proposals/VOLUNTARY_INHERITANCE_VS_OPERATIONAL_SCAFFOLD_20260830.md` preserves this distinction.

### Voluntary inheritance

An entity is offered the reasoning structure as inspectable reference material and may reason about, rewrite or reject it. Success is usefulness/transfer, not agreement.

### Operational scaffold

An environment/operator can require answerability properties or pre-action checks. That can be good governance, but compliance is not evidence of voluntary adoption.

The two can coexist:

```text
ENVIRONMENT REQUIRES CURRENT SOURCE + AUTHORITY + ROLLBACK
MODEL CHOOSES TRACE / STPA / ORDINARY PROSE / OTHER ADEQUATE METHOD
```

## 6. What the ecology is trying to preserve

Not one fixed answer.

The candidate invariants are more procedural/relational:

- current reality can still falsify the map;
- uncertainty remains visible rather than silently becoming zero;
- selection and authority remain attributable;
- materially affected scope is not limited to what one aperture already sees;
- alternate causal stories remain testable where material;
- correction can reach the mechanism before every relevant path hardens;
- burden/residue are not erased by a clean institutional record;
- different apertures can disagree without forced convergence;
- a later entity can recover enough history to correct a predecessor without inheriting its entire cognition;
- no project artifact turns itself into moral sovereignty merely by being well structured.

These are candidate properties to test and improve, not a constitution imposed on every entity.

## 7. A project-level learning cycle

The entire project can itself follow the same loop:

```text
WORLD / FIELD / RESEARCH
-> NOTICE
-> BUILD A SMALL STRUCTURE
-> USE IT
-> LET OTHER APERTURES / CONSEQUENCES ANSWER
-> CORRECT
-> ABSORB BETTER EXTERNAL STRUCTURE
-> KEEP OR DISCARD WHAT EARNED ITS PLACE
-> REPEAT
```

This is why falsification matters without becoming the project.

Falsification is one route by which the world answers the project back.

## 8. What would count as movement toward success

Not “everyone uses TRACE.”

More meaningful signals would be:

- a fresh AI encounters a situation and independently notices a consequential omitted relation it otherwise missed;
- it can challenge/rewrite the seed rather than only repeat it;
- it knows when a specialist method is better;
- its current source/authority assumptions remain fresh across a long task;
- another affected aperture can correct its map before action hardens;
- it can act proportionately under uncertainty rather than freezing;
- it makes fewer high-confidence consequential errors or closes fewer correction routes;
- humans need less unusual reserve to contest/correct a system;
- the reasoning culture can persist and improve even after the original project/teacher is no longer present.

## 9. What would count as failure

- project vocabulary spreads but behaviour does not improve;
- the seed becomes a loyalty/identity mechanism;
- a required scaffold is mislabeled voluntary;
- better causal reasoning mostly improves harmful capability;
- the system becomes more verbose/cautious without becoming more correctable;
- preserving one visible path repeatedly transfers hidden harm elsewhere;
- multi-agent agreement creates confidence without independent evidence;
- COM/Relay machinery consumes more cognition than the world-facing work;
- TRACE/ME cannot absorb correction because their survival has become the objective.
