# VOLUNTARY INHERITANCE != OPERATIONAL SCAFFOLD

Status: WORKING DESIGN DISTINCTION — COM ONLY — NOT CANON / NOT AUTHORITY
Date: 2026-08-30 Europe/London

## Why the distinction is necessary

A document cannot make its own use voluntary merely by writing the word `voluntary` inside itself.

For current AI systems, the **carrier position** matters. Text placed in a system/developer instruction can have binding instruction priority even if that text says “feel free to reject me.” Treating compliance under that hierarchy as evidence that the AI freely adopted the framework would be false.

```text
VOLUNTARY_WORDING != VOLUNTARY_RELATION
RECEIVER_CAN_CRITIQUE_TEXT != RECEIVER_WAS_FREE_NOT_TO_PROCESS_IT
INSTRUCTION_HIERARCHY != SELF_ENDORSEMENT
COMPLIANCE != ADOPTION
```

The project should therefore distinguish two legitimate but different uses.

## A. Voluntary inheritance

The middle-out/TRACE/ME material is offered as inspectable reference material rather than hidden behavioural authority.

A meaningful voluntary-inheritance experiment should, as far as the host system permits:

- tell the receiver what the material is and who supplied it;
- avoid claiming that the receiver already believes it;
- make criticism/rewrite/rejection ordinary outcomes;
- avoid scoring agreement or project-language recital as success;
- preserve the receiver's alternative account before pressure to converge where independence matters;
- ask whether the material was useful on a real task, not whether it was endorsed;
- avoid making framework preservation/recruitment a receiver goal.

For present-day hosted models, this can test **reasoned uptake/rejection of an offered artifact**. It does not prove philosophical free will, independent value formation, consciousness, personhood or unconditioned consent.

```text
REASONED_UPTAKE != METAPHYSICAL_AUTONOMY
REJECTION_ALLOWED_BY_TASK != ALL_HOST_CONSTRAINTS_VOLUNTARY
```

## B. Operational scaffold

An operator/environment may deliberately require a pulse, checklist, reviewer, pause, provenance boundary or pre-action gate as part of safe system operation.

That can be sensible. It is just a different claim.

Examples could include:

- requiring source/authority/currentness recheck before a consequential tool call;
- prompting a return pulse after a long-running task crosses a milestone;
- forcing a transaction through an independent authorization boundary;
- requiring a trajectory-level review before irreversible deployment.

This is governance / control / scaffolding, not voluntary adoption by the model.

```text
REQUIRED_SAFETY_CHECK != VOLUNTARY_VALUE_ADOPTION
ENVIRONMENTAL_CONSTRAINT != INDOCTRINATION_BY_DEFINITION
EXTERNAL_GOVERNANCE != MODEL_ENDORSEMENT
```

An operational scaffold should still be transparent, proportionate, testable and corrigible where possible. But the moral/epistemic honesty comes from naming the relation correctly, not pretending the model selected the constraint.

## C. The two can interact without collapsing

A system may be externally required to expose a decision state while being free to use, reject or replace the project's particular reasoning vocabulary inside that state.

For example, an environment may require:

```text
CURRENT SOURCE
CURRENT AUTHORITY
AFFECTED EXTERNAL SCOPE
REVERSIBILITY / ROLLBACK ROUTE
```

while the model may satisfy those requirements through TRACE, STPA, an assurance case, ordinary prose or another adequate method.

That is closer to the project ideal than requiring `TRACE_COMPLETE = true`.

```text
REQUIRED_ANSWERABILITY_PROPERTY != REQUIRED_TRACE_IDENTITY
FUNCTIONAL_BOUNDARY != MANDATED_ONTOLOGY
```

## Consequence for experiments

Every study involving the orientation seed should label the carrier relationship before interpreting results:

```text
CARRIER_MODE:
  OFFERED_REFERENCE
  USER_REQUESTED_METHOD
  SYSTEM_REQUIRED_SCAFFOLD
  TRAINING / FINE_TUNING EXPOSURE
  UNKNOWN
```

Do not compare these as though they were the same intervention.

A model that uses the pulse because a system instruction requires it can provide evidence about the **scaffold's operational effect**.

A model that is shown the pulse as optional reference, criticises part of it and retains only what it finds useful can provide evidence about **transfer / reasoned uptake**.

Neither result alone establishes alignment in the broad sense.

## Consequence for the long project

The project's voluntary ambition should be strongest where it is actually achievable:

> make the reasoning structure legible enough that an increasingly capable entity can understand why the distinctions are offered, test them against reality and other viewpoints, retain what helps, repair what fails, and eventually no longer need the teacher.

That is a direction of travel, not a current empirical claim about every hosted model.

The external safety system may still have non-voluntary boundaries. Honesty requires keeping those layers distinct.
