## Bottom line

Framework assessment:

> **#364 has a real path to winning the Apart AI x Epistemics Research Sprint, but it is not yet a favourite and the decisive evidence does not exist yet.**

The project is stronger as a competition object now than the original Reader Lens / field-presence audit because it has narrowed to a single live-deployment measurement that:
- matches the Open Track unusually closely;
- uses a complete public government register rather than a toy dataset;
- has a method that has already survived concrete falsification and repair;
- can produce a useful positive, negative, mixed, or method-failure result;
- is reproducible down to source bytes;
- routes findings to the actual standard owner instead of claiming a replacement framework.

The winning case is conditional on November producing a crisp population result and a clear evidence path.

## Current weaknesses

### 1. Headline result unknown — DECISIVE

There is no winning result yet.

A clean method without a consequential result can still be a solid submission but may not win.

### 2. Coding judgement — MATERIAL

Route discovery and target binding involve interpretation.

The 16-case calibration showed meaningful first-pass disagreement, especially on route inclusion.

Mitigation:
- codebook v2;
- exact evidence rows;
- differentiated coding;
- disagreement preservation;
- no score.

### 3. Innovation ceiling — MATERIAL

The project cannot honestly claim:
- contestability theory;
- tool-output/process distinction;
- “transparency != contestability”;
- generic register-usability critique.

The contribution is an implementation measurement.

This can still win if the measurement is consequential and well executed, but it is not a grand-theory novelty play.

### 4. No causal/user-impact result — MATERIAL

#364 measures public legibility, not whether affected people successfully obtain redress.

Do not fake an impact claim.

### 5. Pre-sprint work boundary — MATERIAL

September contains substantial preparation.

Mitigation:
- disclose it;
- keep full-population result uncomputed;
- make fresh acquisition + census + reconciliation + analysis + report the weekend core;
- re-read live terms before registration/submission.

### 6. Generalist-judge accessibility — REPAIRABLE

A 40-file branch and codebook language can bury the point.

Mitigation:
- one sentence question;
- one diagram;
- one population table;
- four concrete records;
- click-through evidence browser;
- limitations early.

## Conditional win test

### First-place credible if, in November:

1. live rules permit the prepared-method / fresh-result boundary;
2. full census completes reproducibly;
3. coding disagreements are bounded and inspectable;
4. one material pattern is clear enough to state in two sentences;
5. concrete examples make the consequence obvious to a generalist judge;
6. every headline number links to evidence;
7. report stays short and accessible;
8. no stronger owner has already published the same **UK ATRS route→target→actor→initiation population measurement**.

### Likely solid but not winning if:

- result is technically correct but diffuse;
- evidence table is strong but headline consequence is weak;
- method needs extensive post-hoc repair;
- presentation reads like an ontology paper;
- the result is mostly descriptive version trivia.

### Kill rather than submit if:

- live rules make the work ineligible;
- codebook collapses;
- exact owner found;
- relation measurement reduces to arbitrary free-text classification;
- interestingness requires overclaim.
